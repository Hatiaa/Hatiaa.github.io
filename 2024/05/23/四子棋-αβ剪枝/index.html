四子棋AI——α-β剪枝算法

发表于2024-05-23|更新于2026-06-06
|字数总计:2.1k|阅读时长:7分钟|阅读量:

在人工智能领域，博弈问题一直以来都是一类具有代表性的研究课题，博弈问题中一些新课题的提出，也不断的推动着人工智能学科的发展。

四子棋是一种典型的博弈游戏，实现四子棋 AI 需要用到剪枝算法、棋局评价、威胁检测与排除等算法。

四子棋游戏规则

游戏双方分别持不同颜色的棋子，设 A 持白子，B 持黑子，以某一方为先手依次落子。假设 A 为先手，落子规则如下:在 M 行 N 列的棋盘中，棋手每次只能在每一列当前的最底部落子，如图中的红点处所示，如果某一列己经落满，则不能在该列中落子。在图形界面中，如果在某一列的任意一个按钮上点击，会自动在该列的最低端落子。

棋手的目标是在横向、纵向、两个斜向共四个方向中的任意一个方向上，使自己的棋子连成四个(或四个以上)，并阻止对方达到同样的企图。先形成四连子的一方获胜，如果直到棋盘落满双方都没能达到目标，则为平局。

规则扩展

对于某些大小的棋盘，四子棋是存在必胜策略的，因此扩展以下规则

  • 棋盘的大小是随机的，而不是固定不变的，宽度和高度的范围均为[9:12]
  • 每次棋盘生成之后，会同时在棋盘上随机生成一个不可以落子的位置，如图中的红叉所示。

算法实现

本篇 Blog 主要讲解使用 α-β 剪枝实现的四子棋 AI，由于走步时间限制，且在不考虑剪枝的情况下，极小极大树的节点数量会随树的深度成指数级增长，因此最多实现到了 6 层，单步搜索时长不超过 0.5s。50 个测例 100 场对局最高胜率为 75%（性能远弱于蒙特卡洛树）。

以下统一设棋盘 M 行 N 列，坐标原点位于棋盘左上角，行列均从 0 开始计数。

α-β 剪枝的基础是极小极大算法，模仿人类下棋往前看多步的思考过程。

极小极大方法维护一个节点树，每个节点代表一个走步。每个节点均有 N 个字节点，分别对应 N 列下一步可以走的位置。由于是双方对弈，因此相邻两层节点对应的棋手是不同的。对于 AI 而言，每次使用极小极大树搜索都是为了找下一步的最优解，因此每棵搜索树的根节点玩家都是对手，下一层都是 AI。

以下是一个典型的极小极大树，深度为 4，正方形代表先手（选择子节点中最大的），圆形代表后手（选择子节点中最小的），只有叶子节点才可以直接计算估值（详见估值函数部分）。

我们使用深度优先搜索的方法对所有情况进行遍历，所以在计算完叶子结点的价值之后需要往上回溯计算父节点的价值。如下图，倒数第二层是对方走步，所以需要选择子节点中最小的那个，如下图红色数字：

同理得再往上一层需要选倒数第二层中最大的

下一步同理选择最小的子节点，直到到达根节点

需要注意的是：每构建一棵完整的极小极大树，时间成本为$O(m^{n+1})$，m 为棋盘列数，n 为树的深度，而这一棵树只决定了一步的结果，因此时间成本是非常高的。这就是为什么要引入α-β 剪枝。

α-β 剪枝

按照极小极大树的搜索方法，我们可以得到倒数第二层第一个节点的值为 0

这时我们可以得出如下结论：倒数第三层的最左边的节点（设为节点 A）的值不可能小于 0（因为要选子节点中最大的），于是我们接着向下深搜

搜索到叶子结点-3 之后，我们可以得知，倒数第二层从左往右数第二个节点的值不可能大于-3（因为要选择子节点中的最小值），结合之前我们得出 A 节点的值不可能小于 0 的结论，那么节点 A 的值到这里就可以确定为 0 了，而不需要进一步搜索到值为 3 的叶子节点，所以我们进行如下剪枝

这个剪枝操作剪掉了选择最小值的剩余步骤，称为 α 剪枝。节点 A 的值确定了之后，可以得到节点 B 的值不可能大于 0，所以我们接着往下搜索

得到 C 的值应该不小于 3，但是 B 的值不能超过 0，因此接下来对 C 的子节点的搜索就不需要了，可以剪枝，此次剪枝为先手节点的剪枝，称为 β 剪枝

B 的值确定之后就可以得出结论，根节点的值不可能小于 0，于是继续向下搜索，然后剪枝，依次类推，最终搜索完成得到的树如下图所示

剪枝进行比较的时候注意需要和祖先比较，才能比较彻底的剪枝

总结一下剪枝条件：

  • 后辈节点的 β 值 ≤ 祖先节点的 α 值时，α 剪枝

  • 后辈节点的 α 值 ≥ 祖先节点的 β 值时，β 剪枝
